# 별이 빛나는 밤에 — 오송호수공원 천체관측회 VR

2026년 11월 1일 저녁 오송호수공원(북위 36.64°, 동경 127.33°) 하늘을 휴대폰 VR로 보여 주는 웹 페이지예요.
진행자 노트북의 QR로 참여자들이 접속하고, 진행자가 쇼를 틀면 모든 휴대폰이 같은 장면으로 동기화돼요.

## 페이지

| 주소 | 누가 | 하는 일 |
| --- | --- | --- |
| `index.html` | 참여자 휴대폰 | VR(카드보드) / 화면 모드로 하늘 보기. 별자리를 2초쯤 바라보면 그림이 그려지고 설명이 자동으로 흘러가요. |
| `host.html` | 진행자 노트북 | 접속 QR, 접속 인원, 쇼 재생·일시정지·장면 이동, 장면별 진행자 대본, 참여자 화면 미리보기 |

## 배포 (GitHub Pages)

휴대폰 기울기 센서는 **HTTPS 주소에서만** 동작해서 GitHub Pages로 올려요.

1. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 이 코드가 있는 브랜치, 폴더를 `/ (root)`로 저장
   (비공개 저장소는 유료 플랜이 필요해요. 무료라면 저장소를 공개로 바꿔 주세요.)
2. 1~2분 뒤 `https://<아이디>.github.io/<저장소>/host.html`을 노트북에서 열기
3. 화면의 QR(또는 `Q` 키로 크게)을 참여자들이 휴대폰 카메라로 찍으면 `index.html?room=코드`로 접속돼요

## 관측회 당일 진행

- 노트북과 참여자 휴대폰 모두 **인터넷이 필요**해요(LTE 가능). 동기화 데이터는 노트북 ↔ 휴대폰 사이로 직접 오가고,
  연결을 이어 주는 데만 PeerJS 무료 서버(0.peerjs.com)를 써요.
- 진행자 페이지는 **한 창만** 열어 두세요. 같은 방 코드를 두 창이 쓰면 두 번째 창에 경고가 떠요.
- 노트북 화면이 꺼지거나 절전되면 연결이 끊겨요. 다시 켜면 휴대폰들이 3초 안에 다시 붙어요.
- 키보드: `스페이스` 재생/일시정지, `←` `→` 이전/다음 장면, `Q` QR 크게
- 쇼 중에는 VR 화면도 하늘이 천천히 돌아 대상이 정면에 오고, 화면 모드는 카메라가 자동으로 움직여요.
  설명은 진행자가 육성으로 하고, 휴대폰에는 짧은 자막만 나와요. 대본은 진행자 화면에 있어요.
- 관측 중에는 메뉴의 **야간 적색 모드**를 켜 두면 눈의 암적응이 덜 깨져요.

## 쇼 추가하기

`js/shows.js`의 `SHOWS` 배열에 같은 형식으로 추가하면 메뉴와 진행자 화면에 자동으로 나타나요.
장면마다 `t`(시작 초), `move`(이동 시간), `minutes`(18:00부터 분), `target`(바라볼 대상), `fov`, `highlight`, `figures`,
`title`/`sub`(자막), `note`(진행자 대본)를 적어요. 자세한 설명은 파일 맨 위 주석에 있어요.

## 로컬에서 시험하기

```
python3 -m http.server 8000
```

- `http://localhost:8000/host.html?transport=local` 과 `http://localhost:8000/index.html?transport=local&room=코드` 를
  같은 브라우저의 여러 탭으로 열면 인터넷 없이 동기화를 시험할 수 있어요(BroadcastChannel 사용).
- `index.html?vrtest` 는 센서 없는 컴퓨터에서도 VR 화면으로 들어가게 해 줘요.
